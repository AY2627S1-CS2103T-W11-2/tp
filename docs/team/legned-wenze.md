### Project: BoothManagerPro

BoothManagerPro is a desktop contact manager designed for convention organisers managing exhibitor representatives through typed commands, featuring a command-driven UI with static contact cards, robust validation, and multi-field filtering.

Given below are my contributions to the project.

* **Code contributed**: [RepoSense link](https://nus-cs2103-ay2627-s1.github.io/tp-dashboard/?search=legned-wenze&sort=groupTitle&sortWithin=title&timeframe=commit&mergegroup=&groupSelect=groupByRepos&breakdown=true&checkedFileTypes=docs~functional-code~test-code~other)

* **Enhancements implemented**:
  * Implemented `DataFileRecovery` for automatic corrupted data backup and restoration protection.
  * Implemented display ordering restoration upon command execution and save failures in `LogicManager`.
  * Added boundary tests for parser utility and update feedback.

* **Contributions to the User Guide**:
  * Documented data file recovery and editing caveats.

* **Contributions to the Developer Guide**:
  * Documented Storage component recovery mechanisms and display ordering rollback.
